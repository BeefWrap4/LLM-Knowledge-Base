## 引用规则

1. 版本、价格、上下文长度、benchmark 和法规必须注明核验日期。
2. 优先级为：法律法规/标准与官方文档 → 原始论文/官方仓库 → 权威工程文档。
3. 博客、媒体和社区帖子只能作为线索，不能独立支撑架构、归属或性能结论。
4. 厂商没有披露的模型参数、训练硬件和内部架构统一写“官方未公开”。
